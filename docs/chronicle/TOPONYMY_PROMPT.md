# Задание агенту: «Что значит имя» — коренные названия мест Камчатки

> Черновик промпта по просьбе владельца 03.10. Дополняет `AGENT_PROMPT.md`:
> все его правила (§1 факт из источника, §2 источники, §3 что сдать, §4 чего
> не делать) действуют полностью. Здесь — только то, что особенное у топонимики.

## Зачем

У многих мест Камчатки имя ительменское, корякское, эвенское или алеутское.
Нужны короткие статьи летописи о происхождении этих имён. Цель — правда о
том, **что известно** и **что нет**, а не красивая легенда. У топонимики
особый соблазн: версий обычно несколько, авторитетных источников мало, и
«значит „отец заливов“» звучит убедительнее, чем «предположительно».

## Главное правило топонимики: версия — не факт

- Любая этимология пишется со словом источника: «предположительно»,
  «по одной из версий», «по Куськову», «по Крашенинникову». Без этих слов —
  только то, что источник называет установленным.
- Если версий несколько — приводятся ВСЕ найденные, каждая со своим
  источником, без выбора «правильной» и без ранжирования по правдоподобию.
- Если источник пишет «происхождение неизвестно» — так и пишется. Это
  полноценный результат, а не неудача.
- Запрещено приписывать версию человеку (Стеллеру, Крашенинникову,
  Дитмару), если ссылка на него не стоит в прочитанной странице рядом с
  самой версией. «Говорят, что Стеллер…» — брак.
- Запрещено объяснять, ПОЧЕМУ так назвали («подчёркивало важность бухты для
  коренных народов», «потому что воды были богаты рыбой»), если этого
  объяснения нет в источнике. Это самая частая выдумка в таких текстах.
- Запрещены «легенды», «предания», «старики рассказывают» без названного
  печатного источника с автором и годом.
- Старые написания на картах (Сувачу, Овача…) приводятся только те, что
  названы в источнике, и только с указанием, где они встречены.

## Источники, по убыванию доверия

1. Топонимические словари и научные работы: В. П. Кусков «Краткий
   топонимический словарь Камчатской области» (1967), работы по
   ительменскому и корякскому языкам, «Описание земли Камчатки»
   Крашенинникова (1755), Стеллер, Дитмар, Комаров, Тюшов.
2. Официальные сайты заповедников, парков, музеев, краевой библиотеки
   (kamlib.ru), Камчатского краевого объединённого музея.
3. Википедия — с проверкой разметки: факт с пометкой «нет источника» не брать.
4. Краеведческие сайты (piragis.ru, topkam.ru, kamchatsky-krai.ru) — как
   источник версии с указанием сайта; как единственный источник слова на
   ительменском — нет.
5. Сниппеты поиска, ответы других ИИ, Дзен, туристические буклеты —
   не источник. Только подсказка, где искать страницу.

Каждая страница должна быть открыта и прочитана в этой сессии; в таблице
фактов — дословная цитата с версией и словом источника.

## Что сдать (по каждому имени)

1. Статья `ChronicleArticle` в `lib/chronicle/articles.ts`: `slug` вида
   `toponim-<имя-латиницей>`, `period` — век первого упоминания или «—»,
   `lead` в одну фразу БЕЗ выбора версии («у имени две версии и нет
   установленной»), секции: «Как звучит и у кого», «Версии», «На старых
   картах» (если есть), «Что носит это имя» (места каталога).
   `placeIds` — все места каталога с этим корнем (бухта, река, вулкан,
   посёлок), id брать из `GET /api/places?q=<имя>`, не выдумывать.
2. Таблица фактов `docs/chronicle/drafts/toponim-<имя>.md`: каждая версия →
   URL → дословная цитата → слово-маркер источника («предположительно»,
   «по мнению», «неизвестно»).
3. Строка «НЕ НАЙДЕНО» в отчёте для имён, у которых ни одного источника
   выше 4-го уровня не нашлось. Статью по ним не писать.
4. Тест: `chronicleForPlace(id)` даёт статью, и в тексте есть слово
   «предположительно» или «неизвестно» — сторож против уверенного тона.
   `npx vitest run tests/unit/chronicle-articles.test.ts` зелёный.

## Чего не делать

- Не пушить в `main`, не открывать PR, не трогать базу и описания мест —
  только черновик в своей ветке; решение о сайте за главной сессией.
- Не писать перевод слова без указания языка (ительменский ≠ корякский).
- Не переводить имя самому по словарю: перевод — только тот, что дан в
  источнике целиком.
- Не использовать первое и второе лицо, запахи, звуки, чувства (сторож
  `lib/places/description-voice.ts`).
