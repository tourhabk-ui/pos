Полный текст каждой страницы публикуется check-run'ом `chronicle-page-NN` на коммите маркера (читается через API репозитория). ## Найденные расхождения

1. **кладбище кораблей** — описание про бухту Завойко (52°56′), координата — Северо-Курильск. Плюс: к августу 2024 года 28 затонувших объектов на участке «Северо-Курильск» убраны (Fishnews/Росморречфлот); 30.07.2025 цунами снова выбросило суда на берег. Карточка не должна обещать «ржавые суда на месте».
2. **Перевёрнутый танк** — описание называет советский Т-34-85 на Парамушире; координата на Шумшу, источник — только японские «Ха-го»/«Чи-ха».
3. **Маяк Большерецкий** — «белый маяк» против белых и чёрных колец по источнику.
4. **Маяк Станицкого** — «белая башня с красным фонарём»: источник подтверждает белую каменную башню на 1953 год, цвет фонаря не назван.
5. **Кайныран** — «духи не прощают» — выдумка; это частный этнопарк у Раздольного. Год создания в источнике не назван.
6. **Памятник Берингу** — год установки (1826 у Пирагиса / 1827 по Бичи у Википедии), место 1930-х («Полярная звезда» / площадь Свободы) и год переноса на нынешнее место (1945 / 1946) расходятся — в статье обе версии.
7. **«Ниитака»** — погибших 284 (ru, en) против 328 (ja); координаты 51°30′/156°29′ (en) против 51°33′/156°28′ (ja); нынешняя дата 1922 подтверждена.
8. **Дом дьякона** — внутри одного источника (музей): 80-е годы XIX века по-русски, 90-е по-английски.
9. **Карымский** — см. выше: по координате, вероятно, Бечевинка, но это догадка, не факт.
