## Как читались источники

Из контейнера агента внешние хосты закрыты (WebFetch — EGRESS_BLOCKED, curl — код 000). Страницы читал раннер GitHub Actions: `.github/workflows/chronicle-fetch.yml` + `scripts/chronicle-fetch.py` в этой же ветке, запуск — пуш маркера `docs/chronicle/drafts/.fetch.json`. Для Википедии скрипт берёт чистый текст через API extracts и отдельно печатает строки вики-разметки с пометками «нет источника»/«нет АИ»/citation needed — иначе в чистом тексте пометка не видна. Полный текст каждой страницы публикуется check-run'ом `chronicle-page-NN` на коммите маркера (читается через API репозитория). Четыре партии, 43 адреса, из них прочитано 33; остальные — 404, «статьи нет», DNS и редирект (перечислены в таблицах). Поисковая выдача использовалась только чтобы найти адреса.
