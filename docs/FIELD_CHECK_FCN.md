# Полевая проверка FCN (этапы 1–4) — чек-лист на двух телефонах

> 30–40 минут, iOS Safari + Android Chrome. По образцу `manual-field-check.md`.
> Цель — проверить руками то, что нельзя проверить из контейнера: авиарежим,
> Cache Storage, компас, реальный GPS. Отмечайте ✓/✗ и устройство.

## A. Выбор маршрута и паспорт (этап 1) — при связи

1. `/planning?mode=trail` → «Выбрать маршрут». На вариантах видны бейджи
   («Трек» зелёный / «Набросок» янтарный / «Точки» голубой)?
2. Поиск по месту («Авачинский») — варианты находятся, бейджи есть?
3. Тап по варианту → превью: под названием бейдж, у наброска — оговорка
   «линия построена прямыми между точками»?
4. CTA: у трека — «Открыть навигатор», у наброска/точек — «Открыть
   ориентирование»?

## B. Полевой пакет (этап 2) — сначала при связи, потом авиарежим

5. Зафиксировать маршрут → «Сохранить полевой пакет · N МБ» (N > 0?).
   Прогресс скачивания идёт, по завершении карточка доверия показывает
   «Полевой пакет: готов» с строками Карта/Линия/Точки/Условия?
6. У «Условия» указан возраст («N мин назад»)?
7. **Авиарежим.** Перезагрузить страницу (из PWA/вкладки). Точки и ЛИНИЯ
   маршрута на месте (не только точки)? Карта в оверлее «КАРТА» рисует
   тайлы из кэша?
8. В авиарежиме кнопка «УСЛОВИЯ» показывает снимок из пакета с возрастом,
   а не «спокойно» и не вечную загрузку?
9. iOS: закрыть Safari, подождать минуту, открыть снова в авиарежиме —
   пакет жив? (Если система вычистила кэш — карточка доверия обязана
   сказать «Карта была сохранена, но вычищена системой», не «готов».)

## C. Кокпит (этап 3) — на улице, с GPS

10. Компас: iOS спросит разрешение по кнопке «Включить»? Стрелка ведёт к
    точке; при неподтверждённом компасе стрелка погашена, есть оговорка?
11. Дистанция до точки живая; при потере сигнала (подвал/лифт) цифра
    сереет и подписывается возрастом фикса, прогресс-бар не анимируется?
12. Прогресс: у маршрута со снятым треком — «Маршрут N% · Пройдено X из Y»;
    у наброска — «Точки: N из M · ориентир, не тропа» без процентов?
13. «Показать качество данных» раскрывает источник линии, пакет, GPS?
14. `/on-route` редиректит на `/planning?mode=trail`?

## D. Подготовка к походу (этап 4) — при связи

15. Карточка маршрута → «Собрать план подготовки». Экран тёмный, изолинии
    фоном, шапка стеклянная, карточки действий плотные и читаемые на
    солнце?
16. «N из 7 доменов подготовлены» — сегменты раздельные; после закрытия
    действий цифра растёт, но зелёной галочки на весь экран нет?
17. Ответы: «С ночёвкой» добавляет «Укрытие для ночёвки»; «Группа» —
    «Роли в группе»? Перезагрузка страницы сохраняет ответы и отметки?
18. «Сохранить полевой пакет» в плане показывает РЕАЛЬНОЕ состояние
    пакета (если пакет скачан в B — item зелёный без кликов)?
19. Маршрут с обязательной регистрацией МЧС показывает «Регистрация
    группы в МЧС» с переходом на forms.mchs.gov.ru?
20. Таб «Снаряжение» открывает /tools/equipment с уже выбранным маршрутом?

## E. Регрессии — быстрый проход

21. Главная: плитка «Обстановка в крае» живая (не пустая при работающем
    источнике)?
22. `/offline` (регионы): скачанный регион помечен «Скачан»; прерванная
    закачка (выключить сеть на середине) даёт «Скачан не полностью», а не
    зелёную галочку?
23. Карточка тура открывается, статус дня на месте?

Результаты (устройство, iOS/Android, версия браузера, ✓/✗, скрины) —
в issue с меткой `fcn-field-check` или прямо в чат сессии.
