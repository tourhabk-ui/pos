# Ведар × партнёры: деловой план работы в мессенджерах

Как «Ведар Камчатка» работает с уже подключёнными операторами там, где они привыкли: MAX, Telegram, телефон, почта. Здесь собрано, что уже построено, чего не хватает и что делать по неделям.

Данные взяты из репозитория (main на 16.11.2026) и с vedarai.ru. Всё неподтверждённое помечено. Ведар — информационный портал, а не агентство: заявка не является бронью, оплата идёт оператору напрямую, для партнёров сервис сейчас бесплатный.

Связанная задача: #3476.

## Главное

**Строить с нуля почти нечего.** В коде уже есть «кабинет в чате» MAX и Telegram:

- заявки с кнопками «Подтвердить / Другая дата / Связался / Договорились / Отказ»;
- открытие дат фразой;
- отчёт за период;
- ежедневная сводка.

Главная работа ближайших недель — три вещи:

1. подключить каждого партнёра к боту;
2. сверить с ним календарь;
3. сделать честную разметку «настоящие выезды / любой день сезона» (открытая задача #3476).

**Другие каналы:**

- **WhatsApp.** Есть только входящий Кузьмич для туристов (`app/api/whatsapp/kuzmich`), адрес на проде закрыт. Отправки заявок партнёрам в WhatsApp в коде не нашли.
- **Почта.** В цепочке «заявка → оператор» отправки письма не нашли. Письма в коде есть только туристам и по жилью.
- **Телефон.** В запросе мест это канал ответа туристу. Машину с перевозчиком подтверждает менеджер Ведара вручную.

> **Пробел в календаре.** В `tour_availability` нет признака, который отличал бы настоящий выезд от «любого дня сезона».
>
> - Миграция 812 заполнила дни сезона у туров, где сезон указан.
> - Миграция 1420 открыла все даты по сезону у «Лагуны Экспедиции» по слову владельца, а не по подтверждению оператора.
> - С миграции 1435 есть только `closed_by='platform'` для дат, которые закрыл Ведар.
>
> Разделение заведено задачей #3476 (`schedule_kind`, 5 PR). Она открыта, ни один шаг не отмечен.

## Цели

1. **Сейчас, бесплатно.** Партнёр получает заявки лично в мессенджере и отвечает одним нажатием. Деньги и договор у него напрямую с туристом.
2. **Честный календарь.** У каждого тура либо настоящие выезды, либо явно «любой день сезона, место подтверждает оператор». Никакого заполнения «на всякий случай».
3. **Статистика партнёру.** Сколько заявок пришло от Ведара, сколько он принял и сколько стали поездками. Без выдуманных цифр, только из базы.
4. **Потом, не раньше чем будут цифры:** процент только с подтверждённых поездок. Это агентское вознаграждение, поэтому до этого юрист должен пересмотреть формулировку «не является турагентом» и оферту.

## По каналам: заявка, ответ, даты

- **MAX — основной рабочий канал партнёра** (есть).
  - Заявка приходит с именем и телефоном туриста.
  - Ответ кнопками. Оператор: «Подтвердить / Другая дата». Гид: «Связался / Договорились / Отказ». Перевозчик и прокат: «Беру / Не могу».
  - Даты в «Календаре»: открыть или закрыть день кнопкой либо фразой.
  - Отчёт и сводка.
- **Telegram — для тех, кто живёт в Telegram** (есть, без ПД).
  - Приходит уведомление без ПД: номер заявки и «Входящие».
  - Работают календарь, отчёт и запрос мест.
  - Чтобы увидеть контакт туриста, нужен MAX или кабинет на сайте. Это осознанное правило (трансграничная передача ПД), а не баг.
- **WhatsApp — только для первого контакта с партнёром** (для заявок нет).
  - Через WhatsApp можно переслать ссылку на бота: так задумано в `channel-link.ts`.
  - Заявки туда не уходят, и с ПД уходить не должны: серверы Meta за рубежом.
- **Телефон — живой разговор и подстраховка** (вручную).
  - Онбординг и сверку дат проще проводить звонком.
  - Если партнёр не ответил в боте, звонит менеджер Ведара (как сейчас у перевозчиков).
- **Почта — для тех, кто не пользуется мессенджерами** (в коде не найдено).
  - Отправки заявки оператору на почту в коде не нашли.
  - Если её делать, то только без ПД и со ссылкой в кабинет.
- **Кабинет на сайте — полная версия** (есть).
  - `/hub/operator`: заявки, календарь, аналитика, виджет для сайта оператора, интеграции.

## Черновик первого сообщения партнёру

> **ЧЕРНОВИК — НИКОМУ НЕ ОТПРАВЛЕН.** Отправлять только после «да» владельца, от его имени, по одному, в привычном каждому партнёру канале.

```text
Здравствуйте, [имя]! Это [имя владельца], «Ведар Камчатка» (vedarai.ru).

Ваши туры уже есть у нас на сайте: [ссылка на страницу партнёра]. Заявки от туристов с сайта и из нашего помощника Кузьмича теперь могут приходить вам лично в MAX, с кнопками «Подтвердить / Другая дата». Отвечаете одним нажатием, договор и оплата у вас с туристом напрямую. Мы не турагент, и сейчас для вас это бесплатно.

Чтобы подключиться, откройте ссылку и нажмите «Старт»: [ссылка на бота, действует 72 часа]. В Telegram тоже можно, но контакты туриста мы передаём только в MAX: его серверы в России.

И один вопрос по календарю: по каким турам у вас конкретные даты выездов, а какие вы возите в любой день сезона, если набирается группа? Хотим показывать туристам ровно то, что есть у вас, без догадок.

Если удобнее созвониться, скажите, когда.
```

## Риски и правовые рамки

| Риск | Что делаем |
|---|---|
| 152-ФЗ: контакты туриста уходят партнёру | Согласие на ПД записывается в той же вставке, что заявка (реестр копий согласия, тест `pd-consent-registry`). ПД идут только в MAX. В Telegram, WhatsApp и на почту — только без ПД. |
| Согласие партнёра на его данные и материалы | Материалы сайта партнёра используем только с его согласия (миграция 1321, отзыв возможен). Даты публикуем только с его слов, с источником. |
| Чужие данные | Не копируем каталоги, даты и цены OTA и конкурентов. Atoms и подобные каналы — только как запасной путь и только с согласия партнёра. |
| Процент = агентское вознаграждение | До любого процента: юрист, правка позиционирования «не турагент», договор. Сейчас бесплатно, и в сообщениях не обещаем «выгоднее OTA» без цифр. |
| Даты, которые оператор не подтверждал (1420) | Сверка с Лагуной на неделе 2–3. Неподтверждённое показываем как «уточняется у оператора». |
| Партнёр не отвечает, заявка теряется | Срок 2 часа и честное «оператор не ответил», напоминание раз в сутки, звонок менеджера. |
| Навязчивость | Сводку партнёр выключает сам, ночью тишина, напоминание не чаще раза в сутки. |
