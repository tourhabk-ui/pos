### Запрещено

```
bg-white/10        → bg-[var(--bg-card)] (на сплошных фонах; поверх фото/glass — допустимо)
text-white         → text-[var(--text-primary)] (на сплошных фонах; поверх фото — допустимо)
text-white/70      → text-[var(--text-muted)] (на сплошных фонах; поверх фото — допустимо)
border-white/20    → border-[var(--border)] (на сплошных фонах; поверх фото/glass — допустимо)
text-cyber-cyan / text-premium-gold / bg-premium-* → устаревшие, не использовать
font-black         → font-bold
rounded-2xl        → rounded-lg (кроме glass-элементов и bento-тайлов — там rounded-2xl)
Хардкод hex        → только CSS vars
```

**Glassmorphism (решение владельца 2026-09-26, пересматривает 2026-08-15 и 2026-07-03):**
стекло — полноценный элемент языка Ведара поверх фото, карт, рельефных/топографических
текстур и тёмных подложек, включая экраны полевого контура. Владелец 26.09: «сделай всё-таки
стекло прозрачное, я решил изменить правила» — на уточнение «что стеклом» ответ: **всё,
кроме SOS**. Контракт теперь: **«поверх карты и фото — стекло; непрозрачны только SOS и
подтверждения»**:
- стеклом могут быть слои контекста (шапки маршрута, статус-строки, обзорные и
  action-карточки, bottom nav), **приборы** (компас, плашка азимута, лист с главной цифрой
  навигации) и **предупреждения** (offline, «точка не проверена», «карта не сохранена»):
  `backdrop-blur-md bg-black/40 border border-white/15 rounded-2xl`, плотнее — `.fx-glass-dense`
  (`bg-black/68`), когда под стеклом сложный фон, а на нём текст или цифра;
- предупреждение на стекле узнаётся **кромкой цвета предупреждения** (`--warning`), а не
  сплошной заливкой; кнопки-лекарства внутри («Сохранить», «Докачать») — сплошные;
- **непрозрачными остаются только SOS (`EmergencyAction`, заливка `--danger`) и
  confirmation-диалоги** (включая согласие на обработку данных). Сторож:
  `tests/unit/field-top-compact.test.ts` («у кнопки SOS нет стекла»);
- стекло тёмное в обеих темах — содержимое берёт цвета тёмной темы: `data-theme="dark"` на
  стеклянном контейнере (переопределяет токены внутри) или `--glass-fg` / `--glass-fg-muted`
  для отдельных строк (`globals.css`, `.fx-glass`). Тёмный текст светлой темы на тёмном стекле
  не читается — так было в строке поля 26.09;
- подложка — только чёрная/белая альфа или CSS-токены, не хардкод-hex;
- `prefers-reduced-transparency` / нет `backdrop-filter` → фолбэк без blur на сплошной
  `var(--bg-card)`; смысл и layout не должны зависеть от эффекта;
- на светлых сплошных фонах (светлая тема, `--bg-primary`) стекла по-прежнему нет — там
  блюрить нечего, только сплошной `var(--bg-card)`;
- у отдельных поверхностей есть свои более строгие стандарты со сторожами (карточка тура §11:
  стекло только в герое поверх фото) — они действуют, пока владелец не изменит их отдельно.

## 3. FRONTEND-DESIGN (Anthropic Plugin)

Скилл активируется автоматически при создании UI. Работает **внутри нашей дизайн-системы**.

### Что поощряется

- **Bold typography** через `font-playfair` + крупные размеры (`text-4xl`, `text-5xl`) — заголовки секций, hero, CTA
- **Distinctive layouts** — asymmetric grids, offset cards, full-bleed секции с `--bg-primary`
- **High-impact moments** — hero-секции с мощной типографикой и минимальным декором
- **Context-aware visuals** — дикая природа Камчатки: вулканы, медведи, океан. Не generic travel
- **Micro-animations** — `transition-all duration-200`, subtle scale/opacity. Без flashy keyframes
- **Whitespace as design** — отступы говорят «премиум», не «студент-верстальщик»

### Правила применения

1. Любой цвет — только через CSS-токены (`var(--accent)`, `var(--ocean)` и т.д.)
2. Анимации — только через Tailwind transition-классы, без `@keyframes` в компонентах
3. Шрифты — Playfair Display для заголовков, Outfit для остального. Никаких Google Fonts import
4. Изображения — из `public/images/`, не placeholder.com и не unsplash ссылки
5. Иконки — только `lucide-react`. Никаких emoji
6. Glassmorphism — решение владельца 2026-09-26: поверх фото, карт, рельефных текстур и тёмных подложек стеклом может быть всё, включая приборы и предупреждения; непрозрачны только SOS и confirmation-диалоги; на светлых сплошных фонах стекла нет — см. §2

### Контекст платформы для дизайна

Это премиальная туристическая платформа. Эстетика:
- Тёплая, земная, природная (лаваст, вулканы, тайга)
- Не минималистично-белая, не cyberpunk, не startup-purple
- Суровая красота + доверие + профессионализм
