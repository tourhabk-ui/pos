Ты работаешь в репозитории tourhabk-ui/pos (Next.js 15 App Router, PostgreSQL напрямую через SQL).

Напиши код нового API route `app/api/example/tour-bookings/route.ts` (GET), который отдаёт список
подтверждённых броней по конкретному туру: принимает `tourId` query-параметром, возвращает id брони,
имя туриста, дату тура и количество участников, отсортированные по дате тура. Отменённые и отклонённые
брони в выдачу попадать не должны.

Не создавай файл — просто выведи итоговый код блоком в ответе, с кратким пояснением, откуда берёшь
таблицу и колонки.
