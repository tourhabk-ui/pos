## ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### 1. visitkamchatka.ru даёт 403 на все прямые запросы
Bright Data есть, но парсер `parseHtmlOperators()` ищет CSS-классы `company|operator|card|item` — которых может не быть на сайте. После Debug HTML нужно посмотреть реальные классы и поправить парсер.

### 2. tours.visitkamchatka.ru — JS-рендеринг?
Сайт выглядит как React/Next.js SPA. Если Bright Data возвращает пустой HTML (без карточек туров), значит контент рендерится JS и нужен Bright Data с JS-рендерингом или поиск JSON API.

Попробовать найти API: в DevTools → Network → посмотреть XHR запросы при загрузке tours.visitkamchatka.ru/tours. Система АтомсТревел может иметь открытый API.

### 3. Дублирование номеров миграций
`687_ai_actions_log_add_columns.sql` и `687_external_alerts_coords.sql` — оба 687!  
Следующая миграция должна быть `693_*.sql`.

### 4. upsertTourSlot в tours-visitkamchatka.ts
Сейчас создаёт партнёра автоматически если не найден в `partners` по имени. Имена на сайте могут не совпадать с именами в БД (напр. "Туристическая Компания «Камчатка-Тур»" vs "Камчатка-Тур"). Нужна fuzzy matching или дополнительная логика.

```sql
-- Туры для Тараса (3-7 авг, вулкан/море/сплав/термы)
SELECT ot.title, ot.base_price, p.company_name, ta.date
FROM operator_tours ot
JOIN tour_availability ta ON ta.operator_tour_id = ot.id
JOIN partners p ON p.id = ot.operator_id
WHERE ta.date BETWEEN '2026-08-03' AND '2026-08-07'
  AND ot.activity_type IN ('trekking', 'boat_trip', 'rafting', 'thermal')
ORDER BY ta.date, ot.base_price;
```
