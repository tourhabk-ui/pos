# Pending / Ждёт действия

## SMS-112 на Камчатке (ждёт Артёма из МЧС)

**Задача:** Уточнить у Артёма из МЧС — работает ли канал SMS-112 на Камчатке как официальный экстренный канал.

**Контекст:** В `public/emergency.html` убрана SMS-кнопка, потому что +7(4152)23-53-62 — стационарный номер, SMS на городские линии в России молча теряются.

**Если SMS-112 работает:** добавить в `public/emergency.html` кнопку:
```html
<a id="sms-btn" href="#">SMS 112</a>
```
И в JS при получении GPS:
```js
document.getElementById('sms-btn').href =
  'sms:112?body=' + encodeURIComponent('SOS! Я жив. Мои координаты: ' + lat + ', ' + lng + '. Жду помощи.');
document.getElementById('sms-btn').style.display = '';
```
Также проверить формат `sms:?body=` на реальном iPhone (iOS и Android обрабатывают по-разному).

**Если не работает:** оставить как есть — только копировать координаты и звонить 112 голосом.
