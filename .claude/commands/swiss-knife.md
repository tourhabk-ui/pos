Проверь что платформа остаётся швейцарским ножом туриста, а не рекламным проспектом.

## Философия проверки

**Швейцарский нож** — лёгкий, каждый инструмент нужен, ничего лишнего.
**Чемодан с проспектами** — тяжёлый, реклама операторов, цены везде, кнопка "Забронировать" на каждой странице.

Платформа — это инструмент для безопасного планирования. НЕ маркетплейс.

---

## Что проверять

### 1. Коммерческое просачивание на страницах мест и маршрутов

Запрещено в `app/places/`, `app/routes/`, `components/places/`, `components/routes/`:

```
"Забронировать"
"от.*₽"
"base_price"
"LeadModal"
"TourPaymentModal"
"FlightsBlock"
"HotelsBlock"
"TransfersBlock"
"InsuranceBlock"
"YandexTravelBlock"
"OfferCard"
"ds-btn-primary.*[Бб]ронировать"
```

Разрешено только на: `app/marketplace/`, `app/hub/operator/`

### 2. Разделение сущностей

Места (`places`) — географический факт. Маршруты (`kamchatka_routes`) — путь. Туры (`operator_tours`) — коммерция.

Запрещено:
- `FROM operator_tours` в API для `/api/places/` или `/api/routes/` (кроме блока "туры сюда" в конце)
- `base_price` в компонентах карточки места
- `booking` в компонентах карточки маршрута (кроме МЧС-регистрации)

### 3. Безопасность присутствует там где нужна

Проверить что на страницах маршрутов и мест есть хотя бы одно из:
- `hazard` / `HazardSignal` / `getHazardSignals`
- `mchs` / `МЧС` / `mchs_registration`
- `safety_profile` / `location_safety_profile`
- `kvert` / `KVERT` / `getVolcanoStatuses`

Искать в: `app/places/[id]/`, `app/routes/[id]/`, `components/places/`, `components/routes/`

### 4. Статусная полоса (StatsBand) — не реклама

В `components/homepage/StatsBand.tsx` НЕ должно быть:
- "туров от операторов"
- "партнёров"
- любых упоминаний цены

Должно быть про: маршруты, места, безопасность, МЧС, мониторинг.

### 5. Главная страница — инструмент, не витрина

В `app/page.tsx` НЕ должно быть:
- Activities strip с `/routes?type=` (каталог активностей)
- "Почему Ведар" блок с иконками фич
- Прямых ссылок на marketplace без контекста безопасности

### 6. Кузьмич — гид по безопасности, не менеджер продаж

В `components/homepage/MessengerAgentsSection.tsx` и `lib/kuzmich/core.ts` НЕ должно быть:
- "подберёт оператора"
- "выберите тур"
- ценовых фильтров

---

## Как проверять

Используй Grep для поиска паттернов. Проверяй файлы в:
- `app/places/`, `app/routes/` — страницы мест и маршрутов
- `components/places/`, `components/routes/` — компоненты
- `components/homepage/` — главная
- `app/page.tsx` — корневая страница

## Формат отчёта

```
/swiss-knife АУДИТ — {дата}

КОММЕРЧЕСКОЕ ПРОСАЧИВАНИЕ:
- [ ] {файл}:{строка} — {что найдено} → {где должно быть}

РАЗДЕЛЕНИЕ СУЩНОСТЕЙ:
- [ ] {файл}:{строка} — {нарушение}

БЕЗОПАСНОСТЬ ОТСУТСТВУЕТ:
- [ ] {страница/компонент} — нет блока опасностей / МЧС

СТАТУСНАЯ ПОЛОСА:
- [x] OK / [ ] {нарушение}

КУЗЬМИЧ:
- [x] OK / [ ] {нарушение}

ИТОГ: {N} нарушений
СТАТУС: ШВЕЙЦАРСКИЙ НОЖ ✓ / ЧЕМОДАН С ПРОСПЕКТАМИ ✗
```

Если нарушений нет — выводи:
```
СТАТУС: ШВЕЙЦАРСКИЙ НОЖ ✓
Платформа остаётся инструментом безопасности, а не витриной.
```
